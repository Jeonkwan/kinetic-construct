02 / CORE PRINCIPLES

Three rules of technical communication.

1. Semantic over Decorative

Colors encode functional roles: Indigo for blueprints, Forest Moss for active roots, and Burnt Sienna for state ledgers.

2. Compact Spatial Rhythm

Eliminate nested card padding. A 220px rail and side-docked workbenches keep content visible without endless vertical scrolling.

3. Mechanical Affordances

Interactive elements depress on click with a 2px offset, giving developers immediate tactile feedback.

06 / OPERATIONAL GUARDRAILS

Four infrastructure safety laws.

  • Single Writer per Root: Prevent concurrent state locks and stale execution ordering.
  • Least-Privilege Identities: Service accounts must be scoped per blast perimeter, not shared globally.
  • Atomic Dependency Planning: Local module changes must automatically trigger plans for downstream consumers.
  • State Is Not a Distributed Transaction: Design roots to tolerate partial apply failures safely.
